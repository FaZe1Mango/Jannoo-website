# Jannoo Website

Schwarz-weiße, responsive Portfolio-Website mit Animationen, Projektkarten, Discord-Link und Dark-/Light-Mode.

## Auf GitHub Pages veröffentlichen

1. Erstelle auf GitHub ein Repository namens `jannoo` (oder nutze dein bestehendes Repository).
2. Lade `index.html`, `style.css` und `script.js` in den Hauptordner des Repositories hoch.
3. Öffne **Settings → Pages**.
4. Bei **Build and deployment** wähle **Deploy from a branch**.
5. Wähle `main` und `/(root)`, dann **Save**.
6. Nach dem Veröffentlichen findest du deine Website unter `https://DEIN-USERNAME.github.io/jannoo/`.

## Hinweis zu Konten und Adminrechten

Füge niemals ein Admin-Passwort direkt in HTML oder JavaScript ein: Jeder Besucher könnte es sehen. Für echte Konten benötigst du einen Authentifizierungsdienst und ein Backend mit serverseitig geprüften Rollen. Passwörter dürfen nicht im Klartext gespeichert oder angezeigt werden. IP-Adressen sind personenbezogene Daten; erhebe sie nur mit einem legitimen, transparenten und datenschutzkonformen Zweck.

Diese Version enthält bewusst keine unsichere Fake-Anmeldung oder Passwort-/IP-Überwachung.
